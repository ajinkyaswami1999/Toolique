# Crawl Comparison

Compare two crawls belonging to the same website.

## Compare

- URLs
- status
- titles
- descriptions
- canonical
- links
- redirects
- images
- issues
- scores

## Classify

- NEW
- REMOVED
- CHANGED
- RESOLVED
- UNCHANGED

## Example

```text id="7l1o0e"
Broken Links

Previous: 27
Current: 8

Resolved: 19
New: 0
```

Values must be calculated from the two actual crawl datasets.
