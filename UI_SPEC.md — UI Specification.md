# UI Specification

## Start

Show:

- URL input
- crawl settings
- start button
- explanation of limits

## Crawling

Show:

- progress
- URL counts
- speed
- elapsed time
- current URL
- errors
- controls

## Results

Navigation:

- Overview
- URLs
- Issues
- SEO
- Links
- Redirects
- Content
- Images
- Resources
- Sitemap
- Robots
- Security
- Performance
- Architecture
- Errors
- Export

## Design

Use Toolique's existing design system.

Requirements:

- responsive
- accessible
- dark mode
- data-dense
- fast
- minimal unnecessary animation

Never sacrifice usability for decoration.
