# Acceptance Criteria

The crawler is production-ready only when all of the following are true:

- [ ] Real URL crawling works
- [ ] 10,000 URL limit works
- [ ] Dynamic discovery works
- [ ] Normalization works
- [ ] robots.txt works
- [ ] sitemap works
- [ ] HTTP analysis works
- [ ] redirects work
- [ ] internal links work
- [ ] external link checking works
- [ ] broken links work
- [ ] SEO analysis works
- [ ] content analysis works
- [ ] image analysis works
- [ ] resource analysis works
- [ ] structured data works
- [ ] security analysis works
- [ ] performance observations work
- [ ] architecture works
- [ ] issue engine works
- [ ] scoring works
- [ ] realtime progress works
- [ ] pause/resume works
- [ ] partial results work
- [ ] exports work
- [ ] comparison works
- [ ] SSRF protection works
- [ ] rate limiting works
- [ ] large crawls remain stable
- [ ] no fake data exists
- [ ] no AI exists
- [ ] no static website-specific data exists
- [ ] every metric is traceable
