# Page Inspector

Selecting a page opens:

1. URL
2. HTTP
3. SEO
4. Content
5. Headings
6. Links
7. Images
8. Canonical
9. Hreflang
10. Indexability
11. Structured Data
12. Open Graph
13. Twitter/X
14. Resources
15. Security
16. Performance
17. Discovery
18. Raw Data

Every displayed value must originate from that page's crawl record.
