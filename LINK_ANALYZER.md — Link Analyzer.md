# Link Analyzer

## Internal Links

Store:

- source
- destination
- anchor
- rel
- status
- crawl depth

## External Links

Store:

- source
- destination
- hostname
- anchor
- status if checked

## Detect

- broken links
- redirect links
- orphan candidates
- pages with no inbound links
- highly linked pages
- weakly linked pages

## Important

Never call an unchecked external URL broken.

Use:

`NOT_CHECKED`

when external link verification is disabled.
