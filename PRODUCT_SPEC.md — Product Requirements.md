# Product Specification

## Target Users

- developers
- QA engineers
- SEO professionals
- website owners
- agencies
- students
- technical auditors

## Primary User Flow

1. Open Website Crawler.
2. Enter URL.
3. Configure crawl.
4. Start crawl.
5. Observe live progress.
6. Wait for completion or inspect partial results.
7. Open dashboard.
8. Explore issues.
9. Inspect individual pages.
10. Export data.

## Crawl Configuration

- start URL
- maximum URLs
- crawl depth
- robots.txt
- subdomains
- external links
- JavaScript rendering
- request delay
- concurrency
- URL parameter handling
- user agent

## Main Dashboard

Show actual:

- discovered URLs
- crawled URLs
- successful URLs
- redirects
- 4xx
- 5xx
- failed URLs
- blocked URLs
- skipped URLs
- images
- scripts
- stylesheets
- external resources
