# Security Analyzer

This is passive analysis only.

Do not perform penetration testing.

## Headers

Check:

- HSTS
- CSP
- X-Content-Type-Options
- Referrer-Policy
- Permissions-Policy
- X-Frame-Options
- COOP
- CORP
- COEP

## HTTPS

Check:

- HTTPS
- HTTP to HTTPS redirect
- mixed-content references
- TLS information where safely available

## Classification

Use:

- PRESENT
- MISSING
- MALFORMED
- NOT_AVAILABLE
