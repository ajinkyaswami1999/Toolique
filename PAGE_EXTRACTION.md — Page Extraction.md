# Page Extraction

## HTML

Extract:

- title
- meta description
- meta robots
- canonical
- hreflang
- headings
- links
- images
- scripts
- stylesheets
- iframes
- structured data
- Open Graph
- Twitter/X
- language
- viewport

## Text

Extract visible text where possible.

Calculate:

- word count
- character count
- paragraph count

## Safety

Never execute extracted page JavaScript inside the Toolique application context.

Sanitize data rendered into the UI.
